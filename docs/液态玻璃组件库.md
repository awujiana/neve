# 液态玻璃组件库（`ui::glass`）

> 把「玻璃」从页面里散落的 `.bg()` / `.border_1()` / `.shadow(vec![...])` 收成一套
> **参数 → 解析 → 组件** 的可复用库。本文档是组件库的 API 说明、设计取舍与接入指南。
>
> 适用范围：`Névé 粒雪` 的 GPUI 界面层。窗口层的真实背景模糊仍由
> `core::appearance::Material` 驱动（Windows 下是 DWM 亚克力），组件库只负责**玻璃表面**。

---

## 1. 这是什么 / 不是什么

**是**：一组返回 `Div` 的无状态 builder，加上一套不含颜色的参数模型与一个纯函数解析器。
调用方照常 `.child(...)` 组装，组件库不接管布局、不持有状态、不读配置文件。

**不是**：

- 不是 WebGL / Skia shader 的移植。GPUI 0.2 没有自定义 fragment shader 接口；
- 不是 `backdrop-filter` 的等价物。真实背景模糊交给窗口层的系统合成；
- 不是物理玻璃渲染。没有路径追踪、没有环境贴图、没有真实 IOR，做的是**屏幕空间近似**；
- 不自带颜色。所有颜色从 `ui::theme::Glass` 令牌派生，见 §9。

## 2. 五份参考与取舍

调研对象：

| # | 来源 | 技术栈 | 位置 |

| 3 | `yzrt-master/纯CSS液态玻璃` | 纯 CSS（多重 inset 阴影 + 45° 渐变） | `docs/` 本地副本 |
| 4 | `docs/源码.js` | 油猴脚本（`backdrop-filter` 配方 + 实时调透明度） | `docs/` |
| 5 | [AndroidLiquidGlass 2.0.0-alpha03](https://github.com/Kyant0/AndroidLiquidGlass) | Compose Multiplatform + AGSL RuntimeShader | `docs/` 本地副本 |

五份实现技术栈完全不同，但**调的是同一组量**。把它们对齐后得到组件库的参数模型：

| 概念 | WebGL | GlassExplorer（iOS 私有） | Android Backdrop | CSS / 油猴 | 本库字段 |
|---|---|---|---|---|---|
| 边缘折射带宽度 | `u_edgeWidth` / height map | `inputInnerRefractionHeight` / `inputOuterRefractionHeight` | `refractionHeight` | inset 亮边的 blur / spread | `refraction_height` |
| 折射强度 | `u_refractStrength` / normalScale | `inputInnerRefractionAmount` / `inputOuterRefractionAmount` | `refractionAmount` | inset 亮边条数与 alpha | `refraction_amount` |
| 色散 / 渗色 | RGB 分通道采样 | `inputBleedAmount` / `BleedOpacity` / `BleedBlurRadius` | `chromaticAberration` | — | `dispersion` |
| 磨砂 / 多层模糊 | `u_frostAmount` + blur layer | `inputBlurDistance0..4` + `inputBlurOpacity0..4` | `depthEffect` + blur | `backdrop-filter: blur(15..24px)` | `frost` |
| 斜向高光 | Fresnel + specular | `highlightsDisplayAngle` | `HighlightStyle.Default(angle=45, falloff)` | `:after` 的 45° 两段白渐变 | `highlight_angle` / `highlight` |
| 平滑度 | — | `smoothness`（0..1, step 0.01） | — | — | `smoothness` |
| 白点提亮 | — | `boostWhitePoint` | — | — | 由 `theme::glass()` 的亮端 alpha 下限承担 |
| 深度 / 内容折射 | `u_thickness` | `contentLensing` | `depthEffect` | — | `depth` |

### 逐份结论

1. **WebGL 版**的核心是 `normal → UV 位移 → 背景采样 → 模糊 / rim / specular → 合成`。
   README 自己也说：形状固定时可以预计算 normal map、改用 SVG filter + CSS，不必上 WebGL。
   本项目连 SVG filter 都没有，所以只借**参数的语义**，不借管线。
2. **GlassExplorer** 最有价值的是「参数探索器」这个产品形态：把私有 `CAFilter` 的
   `inputInner/OuterRefraction*`、`inputBleed*`、`inputBlurDistance0..4 / Opacity0..4`
   全部暴露成滑杆实时调。组件库借了两样东西：分层参数命名，以及 §8 的实验室页。
   iOS 的 `inputBlur*0..4` 五层模糊直接给了「用多条渐变阴影近似边缘法线」的依据。
3. **纯 CSS 版**给了最实用的手感配方：`inset 2px -2px 1px -1px rgba(255,255,255,.9)`
   这类**四条对称内高光**，加上 `:after` 的 45° 两端白渐变、`:before` 的模糊暗边、
   以及 `filter: contrast(3)` 的外层对比增强。GPUI 没有 SVG filter 和对比度滤镜，
   但多重 `BoxShadow { inset: true }` 是现成的，于是成了本库边缘亮线的直接来源。
4. **油猴脚本**是工程侧的落地参考：`rgba(255,255,255,.2~.3)` 半透底 +
   `blur(15..24px)` + `1px rgba(255,255,255,.3~.4)` 亮边 + `0 8px 32px rgba(0,0,0,.1)` 投影，
   并把「玻璃透明度」做成 10..80 的实时滑杆。它验证了「半透填充 + 发丝亮边 + 收敛投影」
   这组 trio 在真实桌面背景上够用。
5. **Android Backdrop** 给了库的分层结构：`Backdrop → effects(lens / blur / colorFilter) →
   highlight(HighlightStyle) → shadow(Shadow / InnerShadow)`，效果层与组件层完全解耦。
   它的 AGSL `RoundedRectRefractionShaderString` 用 SDF 的梯度算 `refractedCoord`，
   并明确写了 `chromaticAberration` 只影响边角。本库的 `spec → resolve → surface`
   三层就是照这个分法落的。

## 3. GPUI 的能力边界

调研后确认 GPUI 0.2（本项目锁定的 `gpui-kit 0.7` → `gpui-pre 0.3.9`）缺这些能力：

| 缺失能力 | 后果 | 组件库的替代 |
|---|---|---|
| 自定义 fragment shader / RuntimeShader | 做不了 SDF 折射与 RGB 分通道采样 | 多条对称 `inset` 亮边模拟边缘法线；一对冷暖色细边模拟色散 |
| `backdrop-filter` / 背景模糊 | 面层自己不能模糊后面的内容 | 提高面层 alpha 来「遮挡」；真实模糊由窗口层的 DWM 亚克力负责 |
| 径向渐变、大半径模糊 | 做不出大面积柔光（大 `blur_radius` 还会出现多边形棱边） | 完全不做装饰光斑，见 `AGENTS.md` |
| 线性渐变只有 **2 个 color stop** | yzrt 那种「两端白、中间透明」的三段高光做不出来 | 两个 stop 之间的 **alpha 差**，对应 Android `HighlightStyle.Default(angle, falloff)` |
| 无 blend mode（`Plus` 等） | 白色高光在近白面板上没有对比度 | 亮端把 inset 亮线 alpha 压到暗端的 ~0.45，靠描边与投影分层 |

结论：**借参数模型与层次顺序，不借渲染管线**。

## 4. 架构

```text
src/ui/glass/
├── mod.rs       模块文档与对外 re-export
├── spec.rs      参数：GlassSpec / GlassPreset / lerp      —— 纯数据，不含颜色
├── resolve.rs   解析：spec + theme::Glass → GlassLayers    —— 纯函数，可单测
└── surface.rs   组件：surface / card / panel / pill        —— 返回 Div，无状态
```

为什么要分三层：参考实现里「参数」和「颜色」常常混在一起（CSS 直接写
`rgba(255,255,255,.3)`，shader 把 rim 颜色塞进 uniform）。本仓库有两条硬约束——
**语义色优先**与**玻璃必须真的透**；组件库一旦自己发明颜色，就会绕过
`theme::set_appearance` 的背景链，桌面内容再也透不进来。因此参数层完全不含颜色，
颜色只在解析层从 `Glass` 令牌取。

层次顺序（所有组件共用 `decorate()`，保证一致）：

```text
1. 圆角              rounded(radius)
2. 斜向渐变底        bg(linear_gradient(angle, start, end))
3. 1px 外缘描边      border_1().border_color(outline)
4. 阴影层            shadow([外投影, 主亮线, 对称亮边, 外圈亮边, 色散边, 深度暗边])
```

## 5. API

### 5.1 `GlassSpec`

所有数值允许越界传入，`normalized()` 会夹到合法区间；外部可以直接把滑杆值写进来。

| 字段 | 类型 | 范围 | 作用 |
|---|---|---|---|
| `radius` | `f32` | 0..64 px | 圆角半径（`pill` 固定用 `RADIUS_PILL`，忽略此值） |
| `fill` | `f32` | 0.20..1.50 | 面层不透明度倍率 |
| `refraction_height` | `f32` | 0..32 px | 边缘折射带宽度，决定 inset 亮边偏移 |
| `refraction_amount` | `f32` | 0..1 | 折射强度，决定亮边条数 / 亮度 |
| `dispersion` | `f32` | 0..1 | 冷暖彩边强度 |
| `frost` | `f32` | 0..1 | 磨砂：越大面层越实、高光越弱 |
| `highlight_angle` | `f32` | 0..360° | 斜向高光角度，0 为向上、顺时针 |
| `highlight` | `f32` | 0..1 | 高光强度 |
| `rim` | `f32` | 0..1.50 | 外缘描边倍率 |
| `shadow` | `f32` | 0..1.50 | 外投影倍率 |
| `smoothness` | `f32` | 0..1 | 亮边柔和度，越大层数越少 |
| `depth` | `bool` | — | 是否补一道向内暗边 |

```rust
let mut spec = glass::GlassSpec::clear();
spec.dispersion = 0.6;
spec.frost = 0.1;
let spec = spec.normalized();
```

### 5.2 `GlassPreset`

`GlassPreset::ALL` 给出五个预设，`label()` / `description()` 用于界面，`spec()` 取参数。

| 预设 | 特征 | 用途 |
|---|---|---|
| `Regular`（默认） | 折射与磨砂平衡 | 常规卡片、全界面默认 |
| `Plain` | 无玻璃层 | A/B 对照、低性能降级 |
| `Clear` | 薄面层 + 强折射 + 轻微色散 | 放大镜感的小面积浮层 |
| `Frosted` | 面层最实、高光最弱 | 长文字区域，可读性最好 |
| `Vibrant` | 强色散 + 强高光 | 徽标、选中态等小面积强调 |

### 5.3 `GlassSpec::lerp`

两套参数的线性插值，供预设切换动画与「材质强度」这类连续量使用。
端点精确返回（避免 `0.2 → 0.19999999` 的浮点误差），角度走最短弧，
布尔字段过半才切换。当前界面尚无逐帧过渡，此 API 由单测覆盖。

### 5.4 `resolve()` / `GlassLayers`

```rust
pub fn resolve(
    spec: &GlassSpec,
    glass: &Glass,
    lightness_ratio: f32,
) -> GlassLayers
```

纯函数，返回 `gradient_angle` / `gradient_start` / `gradient_end` / `outline` / `shadows`。
`lightness_ratio` 取 `Appearance::lightness_ratio()`，只用来决定亮端压低白色亮线
（近白面板上白线没有对比度）；颜色本身仍全部来自令牌。

### 5.5 组件

| 函数 | 基底 | 用途 |
|---|---|---|
| `surface(spec, glass, ratio)` | `div()` | 自己决定 flex 方向 |
| `card(spec, glass, ratio)` | `v_flex()` + `gap_3` + `p_4` | 卡片，替代原先散落的 `ui::card()` |
| `panel(spec, glass, ratio)` | `h_flex().items_center()` | 标题栏 / 侧栏 / 条状容器 |
| `pill(spec, glass, ratio)` | `h_flex()` + 胶囊内距 | 徽标、选中态、值标签 |
| `preset_card(preset, glass, ratio)` | `card()` | 一行拿到某个预设的卡片 |

全部返回 `Div`，调用方继续 `.child(...)` / `.gap_*()` / `.p_*()`。

## 6. 用法

```rust
use crate::ui::{glass, theme};

let g = theme::current_glass(cx);
let ratio = theme::appearance(cx).lightness_ratio();

// 默认卡片
let card = glass::card(&glass::GlassSpec::regular(), &g, ratio)
    .child("标题")
    .child("正文");

// 自定义参数
let mut spec = glass::GlassSpec::clear();
spec.refraction_height = 22.;
spec.dispersion = 0.6;
let card = glass::card(&spec, &g, ratio).child("强折射卡片");

// 直接拿解析结果做调试 / 可视化
let layers = glass::resolve::resolve(&spec, &g, ratio);
println!("边缘 {} 层，面层 alpha {:.2}", layers.shadows.len(), layers.gradient_start.a);

// 预设 + 插值（动画过渡）
let from = glass::GlassPreset::Plain.spec();
let to = glass::GlassPreset::Vibrant.spec();
let halfway = glass::GlassSpec::lerp(from, to, 0.5);
let card = glass::card(&halfway, &g, ratio);
```

页面里已有的 `ui::card(cx)` 现在只是组件库的一层薄封装：

```rust
fn card(cx: &App) -> Div {
    let g = theme::current_glass(cx);
    let ratio = theme::appearance(cx).lightness_ratio();
    glass::card(&glass::GlassSpec::regular(), &g, ratio)
}
```

## 7. 参数到视觉的映射

`resolve()` 里的具体规则：

| 效果 | 规则 |
|---|---|
| 面层 | `alpha = glass.surface.a × fill × (1 + frost × 0.35)`，夹到 0.98 留一线透明 |
| 斜向高光 | `sheen = highlight × (1 − frost×0.5) × (1 − smoothness×0.25) × 0.14`，起点 `alpha + sheen`、终点 `alpha − sheen/2` |
| 外投影 | `offset.y = 8 × shadow`，`blur = 24 × shadow × (1 + smoothness×0.35)`，`spread = −6` |
| 主亮线 | 恒定存在，`alpha = glass.highlight.a × refraction_amount × (1 − frost×0.4) × (1 − smoothness×0.2) × (亮端 0.45 / 暗端 0.85)` |
| 对称亮边 | `refraction_amount > 0.20` 时加一对 `(±edge, ∓edge)`，`edge = 1 + refraction_height × 0.18` |
| 外圈亮边 | `refraction_amount > 0.65` 时再加一圈更淡的，模拟 Fresnel 衰减 |
| 色散 | `dispersion > 0` 时加一对冷（h=0.54）/ 暖（h=0.07）inset 边，`alpha ≤ 0.18` |
| 深度 | `depth = true` 时加一道向内暗边 |
| 外缘描边 | `glass.outline.a × rim`；亮暗端由令牌自己决定用亮线还是淡暗线 |

阴影层最多 8 条，常驻 2 条（外投影 + 主亮线）。解析器不缓存，单帧开销可忽略。

## 8. 玻璃实验室

侧栏最后一项「玻璃实验室」是组件库的活示例，也对应 GlassExplorer 的「参数探索器」形态：

- 五个预设按钮（用 `glass::preset_card` / `glass::panel` 搭容器）；
- 一块实时预览卡（用当前 `GlassSpec` 渲染，显示边缘层数 / 高光角 / 面层 alpha）；
- 四行参数步进：折射带宽度（1 px/格）、折射强度 / 磨砂 / 色散（1%/格），
  与设置页滑杆的 1% 精度一致；值标签用 `glass::pill` + `Vibrant`；
- 底部说明用 `glass::surface` + `Frosted` 承载。

**实验参数只影响预览卡**，不写进 `appearance.conf`，也不改全局 `ui::card()`——
避免把实验室里调过头的高色散带到整个界面。参数存在 `AppShell` 内存里，重启回到默认。

## 9. 必须遵守的项目约定

组件库没有豁免权，以下来自 `AGENTS.md`：

1. **语义色优先**：组件库不出现 `rgb(0x…)` 常量。所有颜色经 `theme::Glass` 令牌，
   由 `theme::set_appearance` 投影。
2. **玻璃必须真的透**：`theme.tokens.background` 必须是全透明的，
   `Root` 才不会用实色盖住 DWM 亚克力。组件库的 `fill` 上限 0.98 也是为了这个。
   改动后跑 `scripts/probe_transparency.py`。
3. **压在半透底色上的文字用主色**：直接落在窗口底色的说明文字一律 `foreground`；
   只有落在 `surface` 面板上的文字才用 `muted_foreground`。改动后跑
   `scripts/probe_contrast.py`，正文 ≥ 4.5:1。
4. **不要给背景加装饰光斑**：GPUI 做不出可用的大面积柔光，组件库也不提供该能力。
5. **`unsafe_code = "forbid"`**，禁止 `unwrap` / `expect` / `panic!`。

## 10. 测试与回归

`cargo test --all-targets --all-features` 中组件库相关 14 项：

- `spec.rs`：预设全部已归一化、标签唯一、插值端点 / 中点、角度最短弧、越界夹取；
- `resolve.rs`：渐变方向、磨砂增实、折射增层、首层恒为外投影、所有 alpha 在 0..1、
  亮端压低白色亮线；
- `surface.rs`：五个预设 × 四种组件都能构造、极端参数不崩。

界面改动还需跑：

```bash
python scripts/probe_drag.py          # 窗口拖动 / 滑杆拖拽 / 1% 精度
python scripts/probe_transparency.py  # 窗口真的透
python scripts/probe_contrast.py <png> "名称:x1,y1,x2,y2"
```
